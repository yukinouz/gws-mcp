## 実行ルール

- 手順の詳細は README.md の「必要なもの」「セットアップ」を参照する
- 1ステップごとに完了を確認してから次へ進む。完了済みのステップはユーザーに確認して飛ばしてよい
- 資格情報（credentials.json / token.json / ~/.config/gws-mcp）には触れない。存在確認も含めて、必要な操作はユーザーに依頼する
- エージェントが実行するコマンドは、実行前にユーザーの了承を得る
- 更新内容に応じて、README.md を更新する。

## ステップ

1. **前提の確認**（エージェント）: Python 3.10 以上があるか。Google Workspace アカウントを使うか（同意画面で「内部」を選ぶため）
2. **Google Cloud の準備**（ユーザー）: API の有効化、同意画面を「内部」で設定、デスクトップアプリの OAuth クライアントを作成
3. **JSON の配置**（ユーザー）: `~/.config/gws-mcp/credentials.json` に置き、権限を設定する
4. **インストール**（エージェント）: venv を作成し、`requirements.lock` から依存をインストールする
5. **初回認証**（ユーザー）: ブラウザ操作が必要なため、`! .venv/bin/python scripts/authorize.py` で実行してもらう
6. **MCP クライアントへの登録**（エージェント）: 登録先（Claude Code / VS Code）をユーザーに確認してから登録する
7. **動作確認**（エージェント）: テストを実行し、読み取り系のツール（`calendar_list_events` など）を実際に呼び出す。登録直後はツールが見えないため、必要ならセッションの再起動をユーザーに依頼する
